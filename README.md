# かぞくトーク（団欒AI）プロトタイプ

親子の会話を週の習慣にして、子供の安心感と自己肯定感を高めるアプリのプロトタイプです。
対象は10〜15歳の子供とその保護者です。

**プロトタイプを開く：** https://yujiiwasaki.github.io/Danran/

スマホで開くと、アプリと同じ全画面で操作できます。

## できること

1. **お題ルーレット**：ルーレットを回して、会話のお題を決める（プロトタイプでは「将来と夢」に固定）
2. **盛り上がりスコア**：会話のあとに、家族チームとしての点数と「よかったところ」を表示する
3. **グラレコ**：会話の内容を1枚のイラストにして、アルバムに残す（サブスク会員）
4. **月次ショートアニメ**：1か月分のグラレコから、短いアニメを作る（サブスク会員の買い切り）

画面の下にある「プラン切り替え」で、サブスク会員と無料プランの見え方を切り替えられます。
保護者ページの PIN は、どの4桁でも開きます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | プロトタイプ本体（ブラウザだけで動く1ファイル） |
| `assets/` | グラレコの生成イメージ（8枚） |
| `設計書.md` | アプリの設計書（ドラフト） |

画面に出てくる家族（お母さん・はると・ゆい）は架空の人物です。グラレコ画像は、AIで作ったイメージの例です。
